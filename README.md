# HRHub — نظام إدارة الموارد البشرية المتكامل

نظام HR متكامل لإدارة الموظفين، الحضور والانصراف بالبصمة، الورديات، الإجازات، والرواتب — مبني على Next.js مع تكامل مباشر مع أجهزة البصمة ZKTeco عبر بروتوكول ADMS.

An integrated HR system: employees, biometric attendance (ZKTeco ADMS), shifts, leaves, and payroll — built with Next.js + Prisma + SQLite.

---

## ✨ المميزات

| الوحدة | الوصف |
|---|---|
| 👥 **الموظفون** | ملف كامل لكل موظف (كود، قسم، مسمى، عقد، بيانات وظيفية) |
| 🏢 **الهيكل التنظيمي** | الأقسام والمسميات الوظيفية والعقود |
| ⏰ **الحضور والانصراف** | سجلات البصمة لحظيًا + متابعة الحضور اليومية |
| 🖐️ **أجهزة البصمة** | اتصال مباشر مع أجهزة ZKTeco عبر بروتوكول ADMS (`/iclock`) بدون أي برنامج وسيط |
| 🔄 **الورديات** | تعريف الورديات وإسنادها للموظفين |
| 🌴 **الإجازات** | أنواع الإجازات والطلبات والعطل الرسمية |
| 💰 **الرواتب** | مكونات الراتب، دورات الرواتب، وقسائم الرواتب (Payslips) |
| 📊 **التقارير** | تقارير حضور ورواتب قابلة للتصدير |
| 📥 **استيراد/تصدير** | استيراد الموظفين والبيانات وتصدير التقارير |
| 🔐 **الأمان** | تسجيل دخول بـ Token، صلاحيات (مدير / مستخدم)، وتشفير كلمات السر بـ scrypt |
| 📜 **سجل التدقيق** | تتبّع كل عملية إنشاء/تعديل/حذف في النظام |
| 💾 **نسخ احتياطي** | نسخ واستعادة قاعدة البيانات |

## 🛠️ التقنيات

- **Next.js (App Router)** + TypeScript
- **Prisma ORM** + **SQLite** (قاعدة بيانات ملفية — لا تحتاج سيرفر)
- **Tailwind CSS** + **shadcn/ui**
- تكامل **ZKTeco ADMS** (بروتوكول iclock)

## 🚀 التشغيل

```bash
# 1) تثبيت الحزم
npm install

# 2) إنشاء قاعدة البيانات
npm run db:push

# 3) التشغيل
npm run dev
```

ثم افتح **http://localhost:3000** — عند أول تشغيل ستظهر **شاشة الإعداد الأول** لإنشاء حساب المدير وتهيئة البيانات الافتراضية (الشركة، الأقسام، أنواع الإجازات...).

### اختبار القبول

```bash
bash scripts/acceptance-test.sh
```

يُشغّل اختبارًا شاملاً لكل الوحدات ويحاكي جهاز ZKTeco حقيقيًا (يحتاج السيرفر شغالًا على المنفذ 3000). لمحاكاة جهاز بصمة منفصل:

```bash
node scripts/mock-zk-device.js
```

## 🖐️ ربط جهاز البصمة (ZKTeco / ADMS)

1. من إعدادات الجهاز: **Menu → Comm → Cloud Server (ADMS)**
2. أدخل عنوان السيرفر: `IP السيرفر` والمنفذ `80` (أو منفذ النشر)
3. عنوان الـ endpoint هو `/iclock` — الجهاز سيتصل تلقائيًا وسيظهر في شاشة **الأجهزة**
4. أرقام البصمات تُربط بكود الموظف تلقائيًا

## 📁 بنية المشروع

```
src/
├── app/            # شاشات النظام + API Routes
│   ├── iclock/     # بروتوكول ADMS لأجهزة ZKTeco
│   └── api/        # REST API (موظفين، حضور، رواتب...)
├── lib/            # المصادقة، قاعدة البيانات، التهيئة، التدقيق
prisma/schema.prisma # مخطط قاعدة البيانات
scripts/            # اختبار القبول + محاكي جهاز البصمة
docs/               # الوثائق والمواصفات الكاملة
```

## 🔒 ملاحظات أمنية

- قاعدة البيانات (`db/`) وملف `.env` **غير مرفوعين** على GitHub ولا ينبغي رفعهما أبدًا.
- كلمات السر مخزّنة مشفّرة (scrypt + salt) — لا يمكن استرجاعها.
- عند النشر الفعلي، غيّر كلمات السر الافتراضية من شاشة المستخدمين.
